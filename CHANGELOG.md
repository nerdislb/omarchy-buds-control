# Changelog

## 0.1.0 — preview

- Port nbshell Buds Control to native Omarchy 4 / Quickshell.
- Retain individual batteries, supported noise modes, read-back confirmation and
  the optional BudsLink fallback.
- Add a lifecycle-managed shared controller, request serialization and timeout
  recovery, renamed-device detection and keyboard-first responsive UI.
- Preserve unknown battery readings and prevent background takeover of BudsLink.
- Include a backed-up local installer, tests, CI and MIT provenance documentation.
